# NestPilot | Personal Productivity Dashboard

NestPilot is a personal productivity dashboard designed to help users organise their daily tasks, plan their schedule, track goals, stay motivated, and maintain focused work sessions.

---

## Features

### To-Do List
- Add and manage tasks
- Mark tasks as completed
- Persistent task management
- Interactive task handling

### Daily Planner
- Organize daily activities
- Plan tasks according to time
- Maintain a structured daily routine

### Motivation
- Motivational content
- Encourages consistency and focus
- Helps users maintain a productive mindset

### Pomodoro Timer
- Focus sessions
- Short break
- Long break
- Start, pause and reset controls

### Daily Goals
- Add custom goals
- Categorize goals
- Set priorities
- Set target time
- Track progress
- Mark goals as completed
- Delete custom goals
- Search goals
- Store custom goals using Local Storage

### Weather
- Current weather information
- Temperature
- Weather condition
- Precipitation
- Humidity
- Wind information

### Theme Customization
- Multiple visual themes
- Interactive theme switching
- Personalized dashboard experience

### Date & Time
- Displays the current date
- Displays the current time
- Helps users stay aware of their schedule

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage
- Weather API
- Remix Icon

---

## Current Project Status

### Version: Initial DOM-based Productivity Dashboard

NestPilot is currently being developed as a frontend JavaScript project. The current version focuses on building a strong foundation in HTML, CSS, JavaScript, DOM manipulation, Local Storage, APIs, and interactive UI development.

The project will continue to evolve toward a full-stack productivity platform.
